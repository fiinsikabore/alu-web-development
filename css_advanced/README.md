# CSS, advanced — SmileSchool

This project is the styling of the **SmileSchool** landing page, built from a Figma designer file.
The HTML structure comes from the `html_advanced` project; here I focused on the CSS.

![SmileSchool page](images/capture.png)

## What I practiced

- Flexbox to align the header, the pros, the videos and the footer
- CSS Grid for the 2×2 F.A.Q. layout
- `position: relative` / `absolute` to center the play icon on each video
- `max-width` + `margin: 0 auto` to center blocks
- CSS variables (`--purple`, `--dark-bg`) and shared styles for buttons and titles

## Files

- `index.html`: the page structure
- `styles.css`: all the styles
- `images/`: logo and social media icons
