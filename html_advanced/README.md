# HTML, advanced — SmileSchool

This project is the HTML structure of the **SmileSchool** landing page, built from a Figma designer file.
It focuses only on semantic HTML: no CSS, no style.

![SmileSchool design](https://html-homework-assets.vercel.app/logo.svg)

## Page structure

- `header`: clickable logo and 3 navigation links
- `main`
  - Banner: title, 3 words, button, and the 4 "pros"
  - Quote: testimonial with author and title
  - Videos: the most popular tutorials
  - Membership: 4 benefits and a register button
  - F.A.Q.: 4 questions
- `footer`: logo, social media links and copyright
